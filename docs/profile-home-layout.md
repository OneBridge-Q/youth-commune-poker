# 红圈个人中心与首页排版

首页：紧凑品牌 Banner → 欢迎回来/加入入口 → 活动类型 → 近期活动 → 精彩回顾。欢迎卡不重复摆放个人分值，点击「我的空间」进入个人中心。Banner 保留品牌、三大定位、南山区地址与活动按钮；系统字号变化时允许内容自然撑高，不裁切重要文案。

我的：暖白背景、深色个人名片；头像、昵称、编辑资料以及「我的战力值」「我的魅力值」合成首屏主卡。战力读取 skillPoints，魅力读取 rewardPoints 可兑换余额，点击魅力进入既有规则说明页。下方依次成长履历/精彩手牌快捷卡、报名记录、冠军荣誉、可折叠管理工作台。保留活动管理、回顾、手牌与冠军认证入口；普通会员不显示管理工作台。

天梯（本次口径纠正）：默认**本店会员双榜**，不是好友榜或品牌总榜，不展示额外个人成绩卡。本人与同店其他会员符合条件时共同参与排名。全系统排名已预留独立认证查询接口，暂不展示切换按钮；见 dual-rankings.md。

## 变更边界
本次排名范围修正不改首页和个人中心的代码、排版或数值。规则提示仍只在魅力值详情页。会员、荣誉、报名数据和余额不删除、不重置。不再依赖好友集合。

## 验收
- 首页 Banner → 欢迎信息 → 活动顺序保持不变。
- 我的顶部名片显示头像/昵称及两个真实数值，点击魅力值进入规则页，后台入口保留。
- 天梯显示本店会员，不混入其他分店，不显示额外个人成绩卡；门店未配置时不展示全系统排名。
- 36项榜单与9项排名页面本地模拟测试通过，真实云环境和手机仍需部署验收。
