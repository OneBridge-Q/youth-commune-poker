# 红圈个人中心与首页排版更新

## 本次变化
首页：紧凑品牌 Banner → 欢迎回来/加入入口 → 活动类型 → 近期活动 → 精彩回顾。欢迎卡不重复摆放个人分值，点击「我的空间」进入个人中心。Banner 保留品牌、三大定位、南山区地址与活动按钮，在375px浏览器模拟布局中从约330px降至220px；原生微信字体/系统字号变化时允许内容自然撑高，不裁切重要文案。

我的：暖白背景、深色个人名片；头像、昵称、编辑资料以及「我的战力值」「我的魅力值」合成首屏主卡。战力读取 skillPoints，魅力读取 rewardPoints 可兑换余额，点击魅力进入既有规则说明页。下方依次成长履历/精彩手牌快捷卡、报名记录、冠军荣誉、可折叠管理工作台。保留活动管理、回顾、手牌与冠军认证入口；普通会员不显示管理工作台。

天梯：仅好友双榜，无个人成绩卡；季度魅力值不等于可兑换余额。具体好友数据范围与部署见 dual-rankings.md。

本次不删除会员/荣誉/报名数据，不改现有余额。规则提示仍只在魅力值详情页，首页、个人中心、天梯没有大段警示。

## 验证边界
29项榜单测试 + 12项页面/结构测试在本地通过。WXML按静态测试状态转换为HTML后，检查320、375、430px宽度下三页的横向溢出并观察排版；这不是微信开发者工具编译或手机实测。截图中的分值和活动标题为布局测试数据，不写入云数据库。

## 体验验收
- 首页Banner明显变短，欢迎信息位于Banner和活动之间，底部没有第二张欢迎卡。
- 我的顶部名片显示正确头像/昵称及两个真实数值；资料加载失败显示重试，不冒充余额为0。
- 点击魅力值仍打开规则页；所有原管理入口都能在工作台展开后找到。
- 天梯没有我的成绩，只呈现已确认好友；空关系不出现全体会员。
