# 青年公社 V0.5.1 活动发布与报名

## 交付功能
- 首页和「我的」都有活动广场入口。
- 活动按社交交流、知识分享、户外运动、创业共创、其他分类。
- 管理员在「我的」→「活动管理」创建草稿、发布、取消活动，查看报名名单。
- 会员可打开已发布活动详情、报名、取消报名，在「我的」查看已报名活动。
- 新会员需先注册。权限、报名人身份、活动状态和报名唯一性由云函数校验。
- 不含收费、现金奖励、德州扑克输赢关联、名额上限、候补或签到；本版本适合少量试运营活动。

## 首次部署
1. 在微信开发者工具同步 GitHub 最新代码，确认 app.json 注册 activities、activity-detail、admin-activities 三个页面。
2. 云开发环境 `cloud1-d5girmhw10f03643a` → 数据库 → 创建以下两个集合（如果尚不存在）：`activities`、`activity_signups`。两个集合均设为 **仅管理端可读写**。
3. 右键 `cloudfunctions/activityAdmin`、`cloudfunctions/activityMember`，各选择「上传并部署：云端安装依赖」。不需要重新部署既有会员、荣誉云函数。
4. 编译后用管理员账号在「我的」→「活动管理」创建一场标明“测试”的未来活动，先为草稿，再点击发布。
5. 用朋友的已注册体验员账号进入首页→「青年公社活动」，打开详情点击报名。
6. 管理员在活动管理查看报名名单（出现朋友昵称）；朋友在「我的」→「我已报名的活动」中查看并取消。取消后刷新名单应不再出现该会员。
7. 测试结束后，管理员取消该测试活动，不要与真实活动混淆。

## 云端设计
- `activities`: 标题、分类、时间（当前按 UTC+08:00 存储）、地点、描述、状态 draft/published/cancelled、storeId、创建者、创建及修改时间。
- `activity_signups`: 每个活动和会员的组合使用服务端生成的稳定 _id；状态 applied/cancelled，允许取消后再次报名。
- `activityAdmin`: 管理员/超级管理员权限校验。正式运营前需要补充发布审批、操作审计、活动编辑、取消活动通知及数据权限检查。
- `activityMember`: 公开活动列表与详情；只有已注册会员可报名及取消；报名不产生积分、不涉及付费。
- 数据库集合应仅供云函数访问，勿开放客户端直接写入。

## 限制与后续
- 无活动人数上限、报名截止时间或候补队列，因此不要直接用于严格限额活动。
- 列表单次最多读取 50 条已发布活动；报名名单最多 100 人，后续需要分页和索引。
- 取消活动后，会员的“我已报名”历史可能仍保留该活动的报名快照，未来加入活动状态联动及通知。
- 当前时间按 UTC+08:00 处理，跨时区活动需升级。
- 正式面向公众前，确认微信隐私指引与活动数据处理规则，包括报名资料访问、更正和删除。
