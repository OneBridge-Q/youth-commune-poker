# 青年公社双数值命名与隔离规则（2026-11-16）

## 产品文案
- **战力值**：仅用于展示参与合法、非有价输赢的扑克策略活动时的竞技能力评价。后续才接入经过核验的评级算法；目前显示数据库已有 `skillPoints` 数值。
- **魅力值**：对应会员的社区贡献及合规活动权益积分，未来可以用于兑换门票、礼物、服务权益。其获得途径应当与德州成绩、牌桌筹码、现金/财物输赢、胜负及投注完全隔离；目前显示数据库已有 `rewardPoints` 数值，尚未开发发放、兑换、退款和流水。
- 店内将筹码称为“积分”并不会改变其实际法律或平台性质。严禁将可兑换财物/门票/权益的魅力值与筹码、牌局输赢、战力值双向兑换、挂钩或联动奖励。
- 仅名称变更不会创造计分功能；不得对用户声称已根据真实牌局结果自动计算战力。

## 技术映射（兼容）
`members.skillPoints` → UI 战力值（battlePower）
`members.rewardPoints` → UI 魅力值（charismaPoints）

本次仅改前端展示名称及天梯文案，不重命名数据库字段，不迁移、重置任何会员数值，不修改任何云函数或活动/荣耀记录。未来如需重命名字段，应先引入规范化 ledger/事务性读写和回滚，不能单方面改动读字段。

## 未来实现前置要求
- 战力值：独立的可核验竞技评级与赛事规则；不与财物输赢或实物奖励计算挂钩。
- 魅力值：独立贡献任务和获得记录（活动组织、有效分享、志愿服务等），清晰有效期、权益种类、库存、核销、撤销、反刷和用户协议。兑换规则需结合当地法律与微信服务类目审核。
- 两套流水隔离，管理员操作留审计记录，不能把扑克筹码纳入积分经济体系。
