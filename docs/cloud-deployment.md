# 微信云开发环境部署指南（开发环境）

正式小程序 AppID: `wx38e120d7481c3436`

> 本文仅供开发环境调试。实际云环境 ID 由开发者在微信开发者工具云开发控制台创建，切勿提交 AppSecret、密钥、账号密码到仓库。

## 1. 查看环境 ID
微信开发者工具顶部「云开发」→ 选择环境 → 环境设置/环境信息，复制唯一 **环境 ID（Env ID）**，不是环境名称。

## 2. 本地设置云环境
在 `miniprogram/app.js` 中用 `wx.cloud.init({ env: '真实环境ID', traceUser: true })` 初始化。
若需要继续维护 `app.ts`，保持两者逻辑一致，或者在后续统一编译流水线；目前开发者工具直接使用 `app.js`。

## 3. 指定函数环境
开发者工具左侧右键 `cloudfunctions` → 「当前环境」→ 选择刚创建的环境。云端与小程序端必须是同一环境。

## 4. 创建数据库集合
云开发控制台 → 数据库 → 集合管理，创建：
- `members`
- `hand_records`
- `hand_audit`
- `champion_awards`（目前冠军审核后台尚未实现）

正式使用前将这些集合设置为「仅管理端可读写」或更严格的自定义安全规则；会员通过权限校验的云函数访问，不要直接开放客户端写入。

## 5. 部署云函数（逐个）
左侧 `cloudfunctions` 展开后，右键每个函数文件夹 → 「上传并部署：云端安装依赖」：
- `login`
- `memberHome`
- `adminProfile`
- `highlightAdmin`
- `highlightStats`
- `momentDetail`

部署完成后，在云开发控制台 → 云函数 → 函数列表中核对函数名和版本。

## 6. 验证身份
在小程序调试器中验证 `wx.cloud.callFunction({name:'login'})` 能正常获取 OpenID。请勿在外部公开个人 OpenID。

当前 `memberHome` **不会自动创建会员**，如果集合尚未写入数据，会返回临时的新会员占位信息。管理员工作台需要 `members` 记录中的 `role` 和 `storeId`；仅由可信管理端赋权。

## 7. 业务验证
会员页面 → 管理员录入手牌 → 另一管理员审核 → 会员精彩手牌列表刷新 → 生成并保存海报。

注意：当前还缺少完成所有环节所需的正式会员创建/管理员初始化、重复记录去重、原子审核审计与证书验证等能力；不得将当前工程直接用于真实商业运营或处理高风险个人数据。

## 排错
- `Cloud API isn't enabled`：检查 `wx.cloud.init` 是否在 `app.js` 的 `onLaunch` 被调用。
- `FUNCTIONS_EXECUTE_FAIL`：检查函数名、环境以及是否上传部署。
- `非法的 env`：检查正式小程序 AppID 与 Env ID 关联以及使用的环境。
- 权限错误：核实集合规则、管理员角色与门店归属；不要为排错将业务数据对所有人开放。
