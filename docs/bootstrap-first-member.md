# 首位会员初始化：苏提

首位会员预留编号：YC000001；昵称：苏提；初始技术分与兑换分均为0；段位为待评级。

**重要：本文不代表已经在云数据库创建记录或授予权限。**

## 安全初始化步骤
1. 在小程序本人登录态下调用已部署的 `login` 云函数确认身份，**不要把 OpenID 发到聊天或公开仓库**。
2. 仅由云开发控制台的授权管理员在 `members` 集合创建首条记录。将该账号的真实 `_openid` 写入记录；切勿使用演示值。
3. 数据字段：`memberNo: 'YC000001'`、`nickname: '苏提'`、`role: 'superadmin'`、`storeId: 'store-001'`、`skillPoints: 0`、`rewardPoints: 0`、`rank: '待评级'`。确保 `_openid` 是本人登录得到的微信身份。
4. 创建后刷新小程序首页，调用 `memberHome` 验证 `registered: true`、昵称正确。
5. 管理员页面在当前版本还需审核权限、门店配置和业务测试，切勿开放给真实用户。

## 安全注意
- 首位超级管理员只能由云控制台有权限的人员初始化；普通会员注册接口不得接受 `role`、`storeId`、`skillPoints` 等可越权字段。
- `members` 集合应限制客户端直接读写，会员只能通过校验 OpenID 的云函数获取自己的数据。
- `memberNo` 需在正式版采用服务端唯一性分配；首号仅用于初始化。
- 切勿提交真实 OpenID、AppSecret 或其他凭据到 GitHub。
