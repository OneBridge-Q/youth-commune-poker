# 红圈 club 首页 / 2026-11-16

## 首页定位
品牌 Banner（红圈 club；智力竞技、兴趣社交、青年共创；深圳市南山区）→ 六类活动产品及介绍 → 已发布的近期活动 → 真实往期回顾 → 会员快捷入口。地址仅使用用户已提供的区级信息，不编造门牌、地图坐标或营业时间。

会员内部ID、登录身份、战力值、魅力值余额、报名和荣誉数据不重置；本次前台调整不等于微信公众平台小程序改名或法律主体变更。

## 规则入口（按用户最新要求调整）
首页、个人中心、天梯页不展示整块规则。首页点击「魅力值 ›」或「我的 → 我的魅力值」，进入 `pages/charisma/index` 查看常驻强提醒。规则模板 `templates/value-rule.wxml` 保留，只由该魅力值说明页引用。天梯双榜与季度统计详见 `docs/dual-rankings.md`。

## 活动类型
六类初始产品文案存放在 `miniprogram/utils/club-home.js`，可以继续增加。活动类型不等于已经排期的场次。旧活动暂按标题关键词匹配，未来可在创建表单明确选择 productId。

## 回顾管理
云函数 activityRecaps 和管理页 pages/admin-recaps/index。入口：我的 → 活动回顾管理。复用 activities 的 recap 子字段；无需新集合。管理权限由云端身份确认，门店管理员不能编辑其他门店，写入检查 recap.revision 防止覆盖。

发布必须关联已有、已发布且开始时间已过去的活动；管理员必须确认实际结束、照片有使用权且获得公开展示的必要同意。上传1—3张现场照片，测试开关默认打开，测试回顾不出现在首页。下架不删除活动或报名。

图片放 activity-recaps/<归属标识>/，服务端为已发布、非测试回顾生成短期URL。短期URL过期、下架，不代表已经下载的图片可被追回。正式上线前仍需内容审核、文件体校验/大小限制、撤回渠道、孤立文件清理与容量评估。

## 部署
回顾首次使用仍需部署 activityRecaps 整个目录（云端安装依赖）。首页和榜单的新调整另见 docs/dual-rankings.md。已有会员、活动报名权限不需放宽，不能为了图片上传开放全库或全桶读写。

编译后检查品牌Banner、类型筛选、实际活动、无回顾空状态；没有真实活动时不填充虚构人数或图片。更新代码后重新上传并设为体验版，普通体验成员才能看到新页面。

## 限制
回顾每次最多展示8条，后端试运营查询范围最多100场；尚非无限历史分页。本地模拟测试不等同于真实云环境部署和手机视觉验收。
